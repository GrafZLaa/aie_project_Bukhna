# project/src/

Логическая структура слоёв пайплайна. Физически вся серверная логика
живёт в [`../app/app.py`](../app/app.py) (наследие хакатона), а
подпакеты `src/` реэкспортируют функции по слоям — это удобно для
ноутбуков и тестов и показывает читателю карту кода.

| Подпакет        | Назначение                                                                |
|-----------------|---------------------------------------------------------------------------|
| [`data/`](./data/)       | Рендер PDF → изображения, снятие embedded-текста (PyMuPDF).         |
| [`ocr/`](./ocr/)         | Tesseract multi-pass OCR с предобработкой изображения.              |
| [`rules/`](./rules/)     | **Baseline**: regex + лейбловые экстракторы + нормализация.         |
| [`llm/`](./llm/)         | **Improved**: опциональная доскан-обработка через Ollama.           |
| [`service/`](./service/) | Flask `app` + точка входа `extract_document_payload`.               |
| [`eval/`](./eval/)       | Прогон контрольной выборки, компаратор значений.                    |

Внутри каждого подпакета `__init__.py` импортирует нужные функции из
[`src/_core.py`](./_core.py), который в свою очередь подгружает
`app/app.py` под именем модуля `app`.

См. также [`../README.md`](../README.md) § «Структура проекта».
