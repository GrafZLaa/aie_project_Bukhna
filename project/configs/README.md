# project/configs/

Конфигурационные файлы.

| Файл                                         | Назначение                                                                  |
|----------------------------------------------|------------------------------------------------------------------------------|
| [`default.yaml`](./default.yaml)             | Декларативная карта всех параметров пайплайна (OCR/LLM/Flask/Registry/Eval) со значениями по умолчанию. Рантайм читает не его, а переменные окружения — этот YAML служит документацией и референсом для деплоя. |

Реальные значения переменных окружения задаются в `.env` в корне `project/`
(шаблон — [`../.env.example`](../.env.example)). **Реальный `.env` в репозиторий
не коммитим** (см. [`../.gitignore`](../.gitignore)).

Источники значений (по убыванию приоритета):

1. Переменные окружения процесса (`os.environ`)
2. `.env` (через `python-dotenv`)
3. Хардкод-дефолты в [`../app/app.py`](../app/app.py)

`default.yaml` соответствует пункту 3.
