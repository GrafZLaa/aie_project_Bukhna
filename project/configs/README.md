# configs/

| Файл | Что это |
|---|---|
| `default.yaml` | карта параметров пайплайна (OCR, LLM, Flask, реестр, eval) с дефолтными значениями. Сервис на рантайме читает не его, а переменные окружения. Этот YAML — просто референс для деплоя |

Реальные значения переменных задаются в `.env` в корне `project/` (шаблон — `../.env.example`). Реальный `.env` в репозиторий не коммитим (см. `../.gitignore`).

Источники значений по приоритету: переменные окружения процесса → `.env` через `python-dotenv` → дефолты в `../app/app.py` (им и соответствует `default.yaml`).
