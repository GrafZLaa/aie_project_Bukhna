# project/notebooks/

Ноутбуки эксперимента и анализа.

| Ноутбук                                       | Назначение                                                                  |
|-----------------------------------------------|------------------------------------------------------------------------------|
| [`01_eda.ipynb`](./01_eda.ipynb)              | Разведочный анализ корпуса PDF: типы документов, наличие embedded-текста, распределение по числу страниц, заполненность полей в контрольной выборке. |
| [`02_baselines.ipynb`](./02_baselines.ipynb)  | Сравнение **baseline** (OCR + правила) и **improved** (+ LLM) по field-level accuracy на контрольной выборке `samples/control_samples.json`. Содержит итоговую таблицу и обоснование выбора финального гибридного решения. |

Боевая логика (OCR, правила, LLM, eval) живёт в [`../app/app.py`](../app/app.py)
и реэкспортирована через [`../src/`](../src/) — ноутбуки её только зовут,
ничего не дублируют.
