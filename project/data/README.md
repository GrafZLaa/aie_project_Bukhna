# project/data/

Runtime-данные приложения. В репозитории здесь только маленькие демо-файлы и описания.

## Что появляется при запуске сервиса

- `registry_state.json` — сохранённый реестр обработанных паспортов
  (создаётся автоматически приложением). Может быть большим, в `.gitignore` исключён.
- `feedback_log.jsonl` — журнал пользовательских отзывов через `/api/feedback`.

## Где лежат входные документы для демо

Демонстрационные PDF-паспорта — в [`../приложения/`](../приложения/).
Это **открытые материалы хакатона** (паспорта оборудования от КЭАЗ, ТРЭИ, ТеконГруп —
общедоступный технический формат). Никаких персональных данных.

Эти PDF используются:
- ноутбуком [`../notebooks/01_eda.ipynb`](../notebooks/01_eda.ipynb) — для разведочного анализа;
- ноутбуком [`../notebooks/02_baselines.ipynb`](../notebooks/02_baselines.ipynb) — для замера качества;
- контрольной выборкой [`../samples/control_samples.json`](../samples/control_samples.json).

## Свои документы

Для проверки на собственных файлах класть их сюда не нужно: подавай через UI
(`http://localhost:5000`) или POST'ом на `/api/extract` / `/predict`. Реестр и логи
запишутся в эту же папку.

## Историческое замечание

В этой папке также лежит файл `dataset_autos_full.csv` (~71 МБ) от прежнего
шаблона репозитория `aie_project_Bukhna` — к текущему проекту по извлечению данных
из паспортов он отношения не имеет, можно удалить.
